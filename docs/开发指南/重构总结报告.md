## 配置文件架构

### 标准配置结构
```yaml
simulation:          # 仿真参数
  duration: 3600
  time_step: 60
  description: "..."

communication:       # 通信主题
  state_topics: {}
  command_topics: {}
  action_topics: {}

components:          # 物理组件
  component_name:
    type: "UnifiedCanal"
    model_type: "reservoir"
    initial_state: {}
    parameters: {}

connections:         # 网络连接
  - from: "comp1"
    to: "comp2"

agents:              # 智能体配置
  agent_name:
    type: "LocalControlAgent"
    agent_id: "agent_1"
    # ... 具体配置

analysis:            # 分析验证
  enable_validation: true
  performance_metrics: []
  expected_behavior: {}

output:              # 输出设置
  show_progress: true
  show_final_summary: true
```

## 支持的组件类型

### 物理组件
- **UnifiedCanal**: 统一渠道模型（水库、渠道、河道）
- **Gate**: 闸门模型
- **Turbine**: 水轮机模型
- **Pipe**: 管道模型
- **Valve**: 阀门模型

### 智能体类型
- **PhysicalIOAgent**: 物理输入输出智能体
- **LocalControlAgent**: 本地控制智能体（PID）
- **DigitalTwinAgent**: 数字孪生智能体
- **CentralMPCAgent**: 中央MPC智能体
- **CentralDispatcher**: 中央调度智能体
- **RainfallAgent**: 降雨扰动智能体
- **WaterUseAgent**: 用水扰动智能体

## 使用指南

### 快速开始
1. **选择示例**: 根据需求选择合适的示例目录
2. **查看配置**: 打开对应的 `config_*.yml` 文件
3. **修改参数**: 根据需要调整仿真参数
4. **运行仿真**: 执行 `python run_config_*.py`

### 自定义配置
1. **复制模板**: 基于现有配置文件创建新配置
2. **修改组件**: 调整物理组件参数和连接
3. **配置智能体**: 设置智能体类型和参数
4. **设置验证**: 定义验证标准和性能指标

### 扩展开发
1. **添加组件**: 在 `create_components()` 函数中添加新组件类型
2. **添加智能体**: 在 `create_agents()` 函数中添加新智能体类型
3. **自定义验证**: 在分析部分添加自定义验证逻辑
