## 快速开始

### 系统要求

- **浏览器**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **网络**: 稳定的互联网连接
- **分辨率**: 最低 1024x768，推荐 1920x1080

### 首次使用

1. **访问平台**
   - 打开浏览器，访问 `https://chs-platform.com`
   - 系统会自动检测您的浏览器兼容性

2. **注册账户**
   - 点击「注册」按钮
   - 填写必要信息：邮箱、用户名、密码
   - 验证邮箱地址
   - 完成账户激活

3. **登录系统**
   - 使用注册的邮箱和密码登录
   - 首次登录会显示欢迎向导
   - 完成基本设置

## 用户注册与登录

### 注册新账户

#### 步骤说明

1. **填写基本信息**
   ```
   邮箱地址: your-email@example.com
   用户名: 3-20个字符，支持字母、数字、下划线
   密码: 至少8位，包含大小写字母、数字和特殊字符
   确认密码: 与密码保持一致
   ```

2. **验证邮箱**
   - 系统会发送验证邮件到您的邮箱
   - 点击邮件中的验证链接
   - 验证成功后账户激活

3. **完善个人信息**
   - 姓名、部门、联系方式（可选）
   - 选择用户角色（普通用户/管理员）
   - 设置个人偏好

#### 密码要求

- **长度**: 8-128个字符
- **复杂度**: 必须包含以下至少3种
  - 大写字母 (A-Z)
  - 小写字母 (a-z)
  - 数字 (0-9)
  - 特殊字符 (!@#$%^&*)
- **安全性**: 不能使用常见密码或个人信息

### 登录系统

#### 登录方式

1. **邮箱密码登录**
   - 输入注册邮箱和密码
   - 可选择「记住我」保持登录状态

2. **单点登录 (SSO)**
   - 支持企业AD域登录
   - OAuth2.0第三方登录

3. **双因素认证 (2FA)**
   - 启用后需要额外的验证码
   - 支持短信、邮件、认证器应用

#### 忘记密码

1. 点击「忘记密码」链接
2. 输入注册邮箱地址
3. 查收重置密码邮件
4. 点击邮件链接设置新密码

## 仿真管理

### 创建仿真

#### 基本设置

1. **仿真信息**
   ```
   仿真名称: 描述性名称，便于识别
   描述: 详细说明仿真目的和内容
   标签: 用于分类和搜索的关键词
   ```

2. **仿真配置**
   ```
   仿真时长: 设置仿真运行的总时间
   时间步长: 计算的时间间隔
   输出间隔: 结果保存的频率
   求解器: 选择适合的数值求解方法
   ```

3. **参数设置**
   - **物理参数**: 温度、压力、流量等
   - **边界条件**: 初始条件和边界约束
   - **材料属性**: 密度、粘度、导热系数等

#### 高级配置

1. **网格设置**
   - 网格类型：结构化/非结构化
   - 网格密度：粗糙/中等/精细
   - 自适应网格：根据梯度自动细化

2. **求解器选项**
   - 收敛准则：残差阈值
   - 迭代次数：最大迭代限制
   - 松弛因子：数值稳定性控制

3. **并行计算**
   - CPU核心数：并行计算资源
   - 内存限制：最大内存使用量
   - 负载均衡：计算任务分配策略

### 运行仿真

#### 启动仿真

1. **预检查**
   - 系统会自动检查配置完整性
   - 验证参数合理性
   - 估算计算资源需求

2. **提交任务**
   - 选择计算队列（快速/标准/高性能）
   - 设置优先级
   - 确认资源分配

3. **监控进度**
   - 实时查看仿真进度
   - 监控系统资源使用
   - 查看中间结果

#### 仿真状态

- **排队中** 🟡: 等待计算资源
- **运行中** 🔵: 正在执行计算
- **已完成** 🟢: 仿真成功完成
- **已失败** 🔴: 仿真执行失败
- **已取消** ⚪: 用户主动取消
- **已暂停** 🟠: 临时暂停执行

## 常见问题

### 登录问题

**Q: 忘记密码怎么办？**
A: 点击登录页面的「忘记密码」链接，输入注册邮箱，系统会发送重置密码邮件。

**Q: 账户被锁定怎么办？**
A: 连续输错密码5次会导致账户临时锁定30分钟，或联系管理员解锁。

**Q: 邮箱验证邮件收不到？**
A: 检查垃圾邮件文件夹，确认邮箱地址正确，或联系技术支持重新发送。

### 仿真问题

**Q: 仿真一直在排队状态？**
A: 系统计算资源繁忙时会出现排队，可以选择低峰时段提交或升级到高优先级队列。

**Q: 仿真失败怎么办？**
A: 查看错误日志，检查参数设置，常见原因包括参数不合理、网格质量差、收敛困难等。

**Q: 如何提高仿真速度？**
A: 优化网格质量、调整求解器参数、使用并行计算、简化几何模型等。

### 数据问题

**Q: 结果数据丢失怎么办？**
A: 系统有自动备份机制，联系技术支持恢复数据。建议定期导出重要结果。

**Q: 导出的数据格式不对？**
A: 检查导出格式设置，确认目标软件的兼容性，或尝试其他格式。

**Q: 图表显示异常？**
A: 刷新页面，清除浏览器缓存，或尝试其他浏览器。

### 性能问题

**Q: 页面加载很慢？**
A: 检查网络连接，清除浏览器缓存，关闭不必要的标签页。

**Q: 文件上传失败？**
A: 检查文件大小限制，网络连接稳定性，或分批上传大文件。

**Q: 系统响应慢？**
A: 避免在系统高峰期使用，关闭其他占用资源的程序。
