## 🚀 快速开始

### 1. 系统概述
CHS-SDK 是一个基于智能体的水利系统仿真平台，支持：
- 多智能体协同控制
- 物理组件建模
- 实时仿真分析
- 配置文件驱动

### 2. 核心概念
- **智能体（Agent）**: 系统中的自主决策单元
- **物理组件**: 水利系统中的物理实体（水库、闸门、泵站等）
- **配置文件**: YAML格式的系统配置
- **仿真引擎**: 核心的仿真执行系统

### 3. 快速上手
1. 阅读 [智能体架构设计](./架构设计/智能体架构设计.md) 了解系统架构
2. 查看 [run_scenario脚本使用指南](./用户手册/run_scenario脚本使用指南.md) 学习基本使用
3. 参考 [物理单元清单](./架构设计/物理单元清单.md) 了解可用的组件类型
