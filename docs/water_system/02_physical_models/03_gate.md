# 物理模型: 闸门 (Gate)

*   **源代码**: `core_lib/physical_objects/gate.py`
*   **接口**: `PhysicalObjectInterface`

## 1. 概述

`Gate` 对象用于模拟水利系统中的控制闸门。它是一个关键的**可控**物理组件，其行为直接受到外部控制信号的影响。

## 2. 数学模型

该模型使用标准的**孔口出流 (Orifice Flow)** 公式来计算通过闸门的流量：
`Q = C * A * sqrt(2 * g * h)`
其中 `C` 是流量系数, `A` 是过水断面面积 (由开度和宽度决定), `h` 是上、下游水头差。

## 3. 关键参数 (`parameters`)

在创建 `Gate` 实例时，需要提供以下核心参数：

*   `width` (米): 闸门的宽度。
*   `discharge_coefficient` (无量纲): 流量系数 `C`，这是一个综合性的经验系数。
*   `max_opening` (0-1, 可选): 闸门的最大物理开度，默认为 1.0 (100%)。
*   `max_rate_of_change` (0-1/秒, 可选): 闸门开度变化的最大速率，用于模拟物理执行器的限制，默认为 0.05 (5%/秒)。

## 4. 状态变量 (`state`)

`Gate` 对象维护并输出以下核心状态变量：

*   `opening` (0-1): 闸门的当前实际开度，范围在 [0, `max_opening`]。
*   `outflow` (立方米/秒): 当前通过闸门的流量。

## 5. 交互与控制

`Gate` 提供了多种灵活的控制方式：

1.  **直接控制**: 在 `step(action, ...)` 方法中，可以通过 `action['control_signal']` 直接传递目标开度。
2.  **消息总线控制**: 在初始化时，可以为 `Gate` 配置一个 `message_bus` 和 `action_topic`。这样，它可以订阅一个主题，并响应两种类型的消息：
    *   **目标开度指令**: 消息中包含 `opening` 键，值为目标开度。
    *   **目标流量指令**: 消息中包含 `gate_target_outflow` 键，值为目标流量。`Gate` 对象会根据当前水头差，**反向计算**出实现该流量所需的目标开度。

这种设计使得 `Gate` 既可以被简单的PID控制器驱动，也可以被更复杂的、以流量为目标的高级调度智能体控制。

## 6. 高级功能：参数辨识

与 `Pipe` 模型类似，`Gate` 对象也包含一个 `identify_parameters()` 方法。该方法可以根据实测数据（水位、开度、流量），自动反向求解出最优的 `discharge_coefficient`，从而显著提升模型的仿真精度。
