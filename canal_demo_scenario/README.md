# 渠道控制系统演示案例

## 概述

这是一个完整的渠道控制系统仿真演示案例，展示了基于智能体的水利系统控制方法。系统包含上游水库、渠道、闸门、下游水库以及分水口等组件，通过PID控制器实现水位自动调节。

## 系统架构

### 物理组件
- **上游水库**: 提供水源，初始水位15米
- **渠道1**: 主渠道，长度5公里，目标水位10米
- **闸门1**: 控制渠道1流量，PID控制
- **渠道2**: 分水渠道，长度3公里，目标水位8米
- **闸门2**: 控制渠道2流量，PID控制
- **下游水库**: 接收来水，初始水位6米
- **分水口1**: 农业灌溉用水
- **分水口2**: 工业用水

### 智能体系统
- **水位感知智能体**: 监测渠道水位，带测量噪声
- **PID控制器**: 根据水位偏差调节闸门开度
- **性能评估智能体**: 监控控制性能，异常报警
- **扰动模拟智能体**: 模拟降雨和用水需求变化
- **数据记录智能体**: 记录仿真数据

## 运行方法

### 1. 使用演示脚本运行
```bash
# 基本运行
python canal_demo.py canal_demo_scenario

# 指定智能体配置文件
python canal_demo.py canal_demo_scenario --agents agents.yml

# 不显示可视化图表
python canal_demo.py canal_demo_scenario --no-viz

# 不生成分析报告
python canal_demo.py canal_demo_scenario --no-report
```

### 2. 使用原始run_scenario.py运行
```bash
python run_scenario.py canal_demo_scenario --agents agents.yml
```

## 仿真参数

- **仿真时长**: 3600秒（1小时）
- **时间步长**: 10秒
- **目标水位**: 渠道1=10米，渠道2=8米
- **扰动时间**: 降雨30分钟后开始，用水需求40分钟后开始

## 输出文件

运行后会生成以下文件：
- `canal_demo_results_YYYYMMDD_HHMMSS.png`: 可视化图表
- `canal_demo_report_YYYYMMDD_HHMMSS.md`: 分析报告
- `canal_demo_output_agents.yml`: 仿真历史数据
- `water_levels.csv`: 水位数据
- `flow_rates.csv`: 流量数据
- `gate_openings.csv`: 闸门开度数据
- `gate1_control.csv`: 闸门1控制指令
- `gate2_control.csv`: 闸门2控制指令

## 控制策略

### PID控制器参数
- **闸门1**: Kp=2.0, Ki=0.5, Kd=0.1
- **闸门2**: Kp=1.8, Ki=0.4, Kd=0.08

### 控制目标
- 维持渠道1水位在10米左右
- 维持渠道2水位在8米左右
- 响应降雨和用水需求扰动
- 最小化控制超调和振荡

## 扰动场景

1. **降雨扰动**（30分钟后）:
   - 持续10分钟
   - 入流量增加15m³/s
   - 测试系统对入流变化的响应

2. **用水需求扰动**（40分钟后）:
   - 持续20分钟
   - 农业灌溉需水5m³/s
   - 工业用水需水3m³/s
   - 测试系统对需求变化的调节能力

## 性能指标

- **水位控制精度**: 目标水位偏差
- **响应时间**: 扰动后的调节时间
- **超调量**: 控制过程中的最大超调
- **稳定性**: 长期运行的水位稳定性
