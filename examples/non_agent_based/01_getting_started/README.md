# 教程 1 · 基础水库-闸门液位控制

## 场景概述与问题描述
本示例构建了一个最小化的闭环控制系统：单座水库通过下游闸门排水，将水位从 14.0 m 拉回到 12.0 m。水库持续接收 65 m³/s 的入流，闸门负责在保持稳定供水的同时抑制水位波动。目标是在 600 s 的仿真窗口内，实现小于 0.02 m 的稳态误差、300 s 内完成 1% 带宽内的调节，且最终水位波动不超过 0.05 m。

## 建模与情景分析原理
- **物理建模**：
  - 水库采用线性库容-水位关系，面积 1.0×10⁴ m²，初始体积 1.4×10⁵ m³。
  - 闸门使用孔口流量公式 \(Q=C·b·h·\sqrt{2gh}\)，并限制最大开度变化速率 0.25 s⁻¹，避免执行器过冲。
- **控制策略**：
  - 反作用型 PID（Kp = −1.0，Ki = −0.015，Kd = −0.12）根据水位误差调整闸门开度。
  - 评价窗口取仿真后 40% 的时间段，并额外留出 10% 的安全裕度，确保指标反映稳态表现。
- **情景分析**：
  - 研究不同运行方式（硬编码脚本 / YAML 配置 / 统一配置 / 通用配置）对建模一致性的影响。
  - 对比阈值通过率与运行日志，验证控制参数对响应速度、稳态误差的影响。

## 四种计算方式与运行步骤
| 运行方式 | 命令 | 说明 |
| --- | --- | --- |
| 硬编码脚本 | `python examples/non_agent_based/01_getting_started/run_simulation.py` | 直接构建对象，输出详细日志与性能汇总。 |
| 多文件配置 | `python examples/non_agent_based/01_getting_started/run_config.py --config config.yml` | 解析 `config.yml` 与 `components.yml`，自动完成拓扑连接与指标校验。 |
| 统一配置 | `python run_unified_scenario.py examples/non_agent_based/01_getting_started/unified_config.yml` | 使用统一 YAML 描述加载组件及控制器。 |

所有运行方式都会在控制指标不达标时抛出异常，避免低性能结果被误判为成功。

## 计算结果与性能指标
| 指标 | 数值 | 阈值 |
| --- | --- | --- |
| 稳态误差 | 0.0075 m | < 0.02 m |
| 最大超调 | 0.0 m | < 10%（相对参考水位） |
| 调节时间（±1%） | 284 s | < 300 s |
| RMSE（稳态窗口） | 0.0075 m | < 0.05 m |
| 最大偏差（稳态窗口） | 0.0075 m | < 0.05 m |

仿真结束时水位稳定在 11.992 m 左右，闸门开度在 0.21 附近小幅微调，满足所有控制与稳定性要求。

## 讨论与改进建议
- **参数灵敏度**：增大 Kp、Ki 可缩短调节时间，但会提高稳态振荡；现有参数在速度与稳定之间取得平衡。
- **模型拓展**：可引入第二座水库或扰动脚本（如突增入流），检验控制器在复合场景下的鲁棒性。
- **自动调参**：结合 `run_config.py` 的性能输出，可接入自动调参工具（如贝叶斯优化）提升闭环性能。
- **可视化**：默认保存的 `01_getting_started_results.png` 展示了水位与闸门开度的时间序列，建议在报告中引用以辅助分析。

通过以上步骤，该示例不仅验证了核心控制器逻辑的正确性，也为后续多组件、多智能体教程奠定了统一的评价基线。
