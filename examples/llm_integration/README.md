# 大语言模型集成示例概述

## 问题描述
该示例演示如何将大语言模型（LLM）引入 CHS-SDK 的建模与分析流程：从自然语言描述中构建配置草稿，自动生成情景脚本，再调用仿真与报表工具完成性能评估。目标是在复杂水利系统（含水库、渠道、泵站与闸门）上实现快速建模与多情景分析，降低工程师的手动配置工作量。

## 建模原理
- **配置到自然语言**：`ConfigToTextConverter` 将 `components.yml`、`topology.yml` 等配置解析成易读描述，作为 LLM 提示的基础。 
- **LLM 辅助建模**：`LLMAutoModelingWorkflow` 根据自然语言描述生成建模指令、情景设置和分析重点，模拟大模型输出结构化建议。
- **情景与仿真生成**：脚本自动创建多种运行情景（正常、干旱、洪水等），为每个情景生成时间序列并输出控制/被控对象的曲线数据。
- **报表生成**：`ReportTemplateSystem` 与增强型分析代理组合，生成图表、Markdown 报告以及 HTML 预览，覆盖控制性能、过程线与扰动响应分析。

## 计算结果
- 自动性能评估：仿真时长 3600 s、时间步长 1 s；校验变量 6 项，质量守恒最大相对误差 0.00%，合理性评分 1.000。
- 报表产物：`output/` 目录下生成多份自动分析报告（如《水利系统自动建模与分析报告》和过程线图表）、时间序列数据表格以及扰动响应曲线 PNG 图像。
- 数据资产：形成针对各关键控制单元的 CSV 时间序列，支持后续二次分析与外部可视化。

## 讨论
LLM 集成流程在保持物理仿真精度的同时，提供了自动化的建模说明和分析报告，适合用作工程前期方案比选或快速复盘的工具。通过统一的输出目录，可追踪 LLM 建模建议与仿真结果的一致性；同时，流程仍允许工程师插入人工干预（调整情景或报告模板）。

## 建议
1. 在部署至生产环境前，可将真实监测数据接入 `simulate_llm_response`，验证 LLM 生成方案与现场数据的一致性。
2. 建议结合企业内的知识库定制提示词模板，进一步提升大模型对特定流域或设备的理解能力。
3. 为确保数据安全，应在工作流中加入敏感信息脱敏与访问控制模块，避免将配置明文直接暴露给外部服务。
