# 简单入流扰动测试说明

## 问题描述
该示例验证在上游水库手动施加阶跃入流扰动的情况下，现有控制策略能否在毫米级精度下稳定水位。扰动按照 100 m³/s → 150 m³/s → 100 m³/s 的阶跃模式在 1–11 s 内循环注入，水库需保持 1 mm 的水位波动上限。

## 建模原理
- 通过 `SimulationBuilder` 复用同一套组件配置，构建由上游水库、三座闸门与下游水库构成的层级网络。
- 在仿真主循环内直接调用 `Reservoir.set_inflow`，与真实调度场景一致地覆盖自动入流。
- 以仿真步长 1 s 逐步推进，配合扰动开始/结束判据与历史记录列表统计水位轨迹。

## 计算结果
- 最大水位偏差：0.000 m（远低于 ±0.001 m 容限）。
- 仿真 15 步后水位保持在 15.000 m，与初始状态完全一致。
- 扰动期间多次核验入流峰值均达到 150 m³/s，确认阶跃信号被准确施加。

## 讨论与建议
- 现有控制结构对该阶跃扰动具有足够鲁棒性，后续可在此基础上叠加更复杂的入流波形以检验动态响应。
- 若需评估控制器的余度，可引入测量噪声或闸门响应迟滞，观察 1 mm 容限是否仍能满足。
- 建议将当前统计逻辑封装为自动化校验模块，便于在批量场景中统一验收控制精度。
