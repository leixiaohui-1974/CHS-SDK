# 网络扰动测试说明

## 问题描述
示例针对增强消息总线在三类网络扰动（固定延迟、丢包、复合扰动）下的传输可靠性进行评估，关注延迟统计与消息送达率，为多代理协调策略提供通信性能基线。

## 建模原理
- 使用 `EnhancedMessageBus` 与 `NetworkDisturbanceManager` 注入延迟与丢包模型，允许对目标主题与代理精确控制扰动范围。
- 通过 `TestAgent` 统一处理发送与接收逻辑，记录消息时间戳、延迟信息以及投递统计。
- 对组合扰动场景同时激活延迟与高丢包扰动，模拟突发网络退化。

## 计算结果
- 延迟扰动：发送 12 条消息，实际平均延迟 0.190 s，记录 16 条延迟消息，延迟统计与配置目标一致。
- 丢包扰动：在 50 次发送中接收 36 条，实际丢包率 28%，符合 30% 设定的统计波动区间。
- 组合扰动：80 条消息共接收 224 条，152 条携带延迟标签，平均延迟 0.064 s（0.019–0.115 s 范围），突发丢包事件触发后系统可自动恢复。

## 讨论与建议
- 延迟扰动的实测均值与抖动范围紧贴配置参数，说明仿真实现能够较真实地复现 QoS 波动，可据此设计通信补偿策略。
- 丢包统计显示 30% 设定下出现 28% 的实际值，属于伯努利事件的预期波动，建议在长序列测试中绘制置信区间。
- 组合扰动验证了消息队列与扰动管理器的协同能力，但也暴露出日志量较大的问题，可在未来引入聚合统计以减轻输出噪声。
