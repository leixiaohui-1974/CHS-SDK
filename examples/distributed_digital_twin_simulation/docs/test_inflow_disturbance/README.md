# 入流扰动稳定性测试说明

## 问题描述
脚本评估动态扰动管理器在 50 m³/s 阶跃入流作用下维持上游水库水位的能力，验证控制误差是否限制在 ±2 mm 之内，并记录扰动激活状态。

## 建模原理
- 依托 `SimulationBuilder` 载入与主工程一致的水库—闸门—渠道网络拓扑。
- 通过 `DynamicDisturbanceManager` 在仿真时间 1–11 s 内注入“inflow_variation”扰动，模拟调度平台发送的台阶入流。
- 仿真以 0.5 s 步长推进，循环中记录水位与入流历史，并同步检查 `_disturbance_active` 标记。

## 计算结果
- 最大水位偏差：0.000 m（满足 ±0.002 m 的精度指标）。
- 入流历史峰值达到 150 m³/s，扰动管理器正确激活并在 11 s 后撤除。
- 最终水位回到 15.000 m，未出现稳态偏差。

## 讨论与建议
- 当前回路对单一阶跃扰动完全抑制，建议在后续测试中叠加随机噪声或多级阶跃以评估鲁棒性边界。
- 可将 `_format_preview` 输出的数据写入结构化报告，便于批量对比不同控制参数下的误差走势。
- 如需扩展至多水库联调场景，应同步复核 `DynamicDisturbanceManager.update` 对多组件的覆盖能力。
