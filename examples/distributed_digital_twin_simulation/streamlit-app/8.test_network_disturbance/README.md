# 网络扰动测试系统 - Streamlit应用

这个Streamlit应用为 `8.test_network_disturbance.py` 脚本提供了一个直观易用的图形界面，让非技术人员也能轻松进行网络扰动测试和分析。**支持从配置文件加载扰动参数**，提供预设配置方案和配置管理功能。

## 🆕 配置文件功能

### 配置文件读取顺序
应用会按以下优先级自动查找配置文件：
1. `examples/distributed_digital_twin_simulation/network_disturbance_config.yaml` (推荐位置)
2. `examples/distributed_digital_twin_simulation/network_disturbance_config.yml`
3. `streamlit-app/8.test_network_disturbance/network_disturbance_config.yaml`
4. `streamlit-app/8.test_network_disturbance/network_disturbance_config.yml`

**配置文件位于父目录**，与原始 `8.test_network_disturbance.py` 脚本同级，便于统一管理。

### 配置文件结构
```yaml
# 测试环境配置
test_environment:
  agent_count: 4          # 测试代理数量 (2-8)
  message_count: 50       # 发送消息数量 (10-200)
  message_interval: 0.2   # 消息间隔，单位秒 (0.1-2.0)

# 网络延迟扰动配置
network_delay:
  enabled: true           # 是否默认启用
  base_delay: 200         # 基础延迟，单位ms (0-1000)
  jitter: 100            # 延迟抖动，单位ms (0-500)
  packet_loss: 0.1       # 丢包率 (0.0-0.5)
  delay_mode: "fixed"    # 延迟模式: fixed, gradual, random

# 数据包丢失扰动配置
packet_loss:
  enabled: false          # 是否默认启用
  loss_rate: 0.3          # 基础丢包率 (0.0-0.8)
  burst_probability: 0.1  # 突发丢包概率 (0.0-0.5)
  burst_duration: 1.0     # 突发持续时间，单位秒
  recovery_time: 2.0      # 恢复时间，单位秒

# 组合扰动配置
combined_disturbance:
  enabled: false          # 是否默认启用
  intensity: 1.0          # 扰动强度倍数 (0.5-2.0)
  duration: 8.0          # 扰动持续时间，单位秒 (1.0-20.0)

# 预设配置场景
presets:
  light_disturbance:      # 轻度扰动场景
    network_delay:
      base_delay: 50
      jitter: 25
      packet_loss: 0.05
    packet_loss:
      loss_rate: 0.1
      burst_probability: 0.05
  
  moderate_disturbance:   # 中度扰动场景
    network_delay:
      base_delay: 200
      jitter: 100
      packet_loss: 0.1
    packet_loss:
      loss_rate: 0.3
      burst_probability: 0.1
  
  heavy_disturbance:      # 重度扰动场景
    network_delay:
      base_delay: 500
      jitter: 250
      packet_loss: 0.2
    packet_loss:
      loss_rate: 0.5
      burst_probability: 0.2
```

### 预设配置方案
- **轻度扰动** (`light_disturbance`): 50±25ms延迟，5%丢包，适合轻微网络问题测试
- **中度扰动** (`moderate_disturbance`): 200±100ms延迟，10%丢包，适合一般网络问题测试  
- **重度扰动** (`heavy_disturbance`): 500±250ms延迟，20%丢包，适合极端网络环境测试

### 配置管理功能
- ✅ **自动加载**: 启动时自动从父目录加载配置文件
- 📥 **配置导出**: 将当前界面设置导出为标准YAML配置文件
- 🔄 **热重载**: 支持运行时重新加载配置文件，无需重启应用
- 🎯 **预设选择**: 通过下拉菜单快速切换不同扰动强度方案
- 📋 **配置状态**: 侧边栏显示配置来源和加载状态
- 💾 **配置管理**: 专门的配置管理面板，包含导入导出功能

## 🎯 业务功能

### 核心业务逻辑
- **网络延迟扰动**：模拟网络延迟、抖动和部分丢包对分布式系统的影响
- **数据包丢失扰动**：模拟网络丢包和突发丢失情况对通信的影响
- **组合扰动测试**：同时应用多种网络扰动观察复合影响效果
- **多代理通信**：模拟分布式系统中多个代理间的消息传递
- **实时性能监控**：统计消息传递成功率、延迟、丢包率等关键指标

### 模块依赖
- **enhanced_message_bus** (EnhancedMessageBus)：负责增强的消息总线通信
- **network_disturbance** (NetworkDisturbanceManager, NetworkDelayDisturbance, PacketLossDisturbance)：提供网络扰动类型和管理
- **使用网络库**：完全集成网络扰动测试核心组件

### 数据源
- **消息传递统计数据**：实时消息发送、接收、丢失统计
- **网络扰动配置参数**：延迟、抖动、丢包率等配置数据
- **通信性能数据**：延迟时间、成功率、代理状态等性能指标

## 📋 功能特性

## 🔧 技术实现

### 核心组件
- **NetworkDisturbanceSimulator类**：封装网络扰动仿真逻辑
- **MockTestAgent类**：模拟测试代理的消息收发
- **自适应模式**：支持真实网络测试和模拟数据两种模式

### 扰动仿真算法
- **延迟仿真**：基础延迟+随机抖动的延迟模型
- **丢包仿真**：基础丢包率+突发丢包的概率模型
- **组合仿真**：多种扰动叠加的复合影响模型

### 数据处理
- **实时统计**：动态更新消息传递统计
- **性能分析**：计算延迟分布、成功率等性能指标
- **结果存储**：基于Session State的结果持久化

## 📝 关键指标说明

### 性能指标
- **总发送消息**：所有代理发送的消息总数
- **总接收消息**：所有代理成功接收的消息总数
- **实际丢包率**：(丢失消息数/预期接收消息数) × 100%
- **平均延迟**：所有成功传递消息的平均延迟时间

### 扰动效果指标
- **延迟效果**：实际测得延迟 vs 配置延迟的对比
- **丢包效果**：实际丢包率 vs 配置丢包率的对比
- **吞吐量影响**：扰动对整体消息吞吐量的影响
- **代理影响差异**：不同代理受扰动影响的差异分析

## 🚨 注意事项

- 确保网络模块正确配置（enhanced_message_bus, network_disturbance）
- 代理数量设置要合理，过多会影响测试性能
- 扰动参数要符合实际网络环境的约束
- 建议先用较小的消息数量进行测试验证
- 组合扰动可能产生复合影响，需要仔细分析结果
