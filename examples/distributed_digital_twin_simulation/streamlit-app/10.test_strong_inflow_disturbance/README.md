# 强入流扰动测试系统 - Streamlit应用

这个Streamlit应用为 `10.test_strong_inflow_disturbance.py` 脚本提供了一个直观易用的图形界面，让非技术人员也能轻松进行强入流扰动测试和验证。

## 🎯 业务功能

### 核心业务逻辑
- **强入流扰动验证**：使用足够大的入流扰动来验证扰动功能确实有效，解决普通扰动效果不明显的问题
- **最大效果追踪**：重点关注扰动过程中的最大水位变化，而不只是最终状态
- **有效性判断**：通过明确的成功/失败标准判断扰动系统是否正常工作
- **强度等级评估**：根据扰动强度自动评估预期效果等级
- **理论验证对比**：强扰动条件下理论计算与实际结果的精确对比

### 模块依赖
- **core_lib.io.yaml_loader** (SimulationBuilder)：负责加载仿真环境和水库组件管理
- **使用core_lib**：直接调用核心库进行强扰动验证，确保测试的真实性

### 数据源
- **仿真环境状态数据**：实时水库状态、组件参数、强扰动响应
- **强扰动配置参数**：大幅度入流增量、扰动时间、强度等级设置
- **最大水位变化数据**：扰动过程中水位的最高点、最低点、变化范围
- **理论计算基准**：基于物理公式的强扰动预期效果

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行应用
```bash
streamlit run streamlit_app.py
```

应用启动后会自动打开浏览器，或手动访问 `http://localhost:8501`

## 📋 功能特性

- **强度等级显示**：自动评估扰动强度(中/强/极强)和预期效果
- **智能预警系统**：根据理论计算自动判断扰动强度是否足够

- **强扰动理论模型**：基于大幅度入流变化的水位预测计算
- **效果等级预评估**：根据预期水位变化自动分级(不足/中等/良好)

- **安全保护机制**：防无限循环和完善的错误处理

### 专业结果分析

## 📝 验证标准详解

### 强扰动成功标准
```
🎉 扰动成功：水位变化 ≥ 1.0 mm
⚠️ 效果中等：0.1 mm ≤ 水位变化 < 1.0 mm  
❌ 扰动不足：水位变化 < 0.1 mm
```

### 理论准确度评估
```
📊 计算精确：理论准确度 > 90%
📈 基本符合：理论准确度 70-90%
📉 需要检查：理论准确度 < 70%
```

### 强度等级定义
```
🔥 极强扰动：入流增量 ≥ 5000 m³/s
💪 强扰动：2000 ≤ 入流增量 < 5000 m³/s
⚡ 中等扰动：1000 ≤ 入流增量 < 2000 m³/s
```

## 📋 关键技术指标

### 水位变化计算
```
理论最大水位变化 = (入流增量 × 扰动持续时间) ÷ 水库表面积
实际最大水位变化 = max(扰动过程中所有水位) - 初始水位
变化准确度 = 100% - |实际变化 - 理论变化| / 理论变化 × 100%
```

### 强扰动设计原则
```
入流增量建议值：≥ 2000 m³/s (基础入流的20倍以上)
扰动持续时间：≥ 10 秒 (确保足够的累积效应)
预期水位变化：≥ 1 mm (确保效果可观测)
理论计算偏差：≤ 30% (确保计算模型有效)
```

## ⚠️ 使用注意事项

### 强扰动配置建议
- **入流增量**：建议设置为基础入流的10-50倍以确保明显效果
- **扰动时间**：建议≥10秒，过短可能无法观察到最大效果
- **总仿真时间**：建议为扰动时间的1.5-2倍以观察完整过程
- **表面积固定**：基于脚本设定固定为100万m²，不建议修改

### 结果解读要点
- **最高水位**：比初始水位的上升量是关键指标
- **理论准确度**：90%以上表示计算模型可靠
- **扰动效果**：重点关注是否达到1mm阈值
- **持续性**：观察扰动结束后水位是否回落

### 故障排除指南
- 如果扰动效果不明显，尝试增加入流增量至5000+m³/s
- 如果理论准确度很低，检查表面积设置是否正确
- 如果仿真报错，确认core_lib环境配置
- 如果结果异常，可切换到模拟模式进行对比分析
