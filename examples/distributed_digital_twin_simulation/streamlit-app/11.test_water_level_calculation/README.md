# 水位变化计算测试系统 - Streamlit应用

这个Streamlit应用为 `11.test_water_level_calculation.py` 脚本提供了一个直观易用的图形界面，让非技术人员也能轻松进行水位变化计算的验证和分析。

## 🎯 业务功能

### 核心业务逻辑
- **水库参数获取**：自动获取并分析水库的完整物理参数（初始水位、体积、表面积、库容曲线等）
- **库容曲线分析**：解析库容曲线数据，计算不同水位段的平均表面积，处理非线性水库几何形状
- **精确理论计算**：基于准确的表面积数据进行水位变化理论计算，而不是使用固定表面积假设
- **计算方法验证**：验证理论计算公式的正确性，确保扰动效果预测的可靠性
- **参数优化建议**：基于计算结果提供扰动参数的优化建议和效果预测

### 模块依赖
- **core_lib.io.yaml_loader** (SimulationBuilder)：负责加载仿真环境和水库组件管理
- **使用core_lib**：获取真实的水库参数和库容曲线数据，确保计算基础数据的准确性

### 数据源
- **水库组件状态数据**：初始水位、初始体积等实时状态信息
- **水库物理参数**：表面积、库容、几何特征等设计参数
- **库容曲线数据**：描述水库体积与水位关系的完整曲线数据
- **计算验证结果**：理论计算过程和结果的详细记录

## 📝 计算公式详解

### 基础水位变化计算
```
理论水位变化 = 额外体积 ÷ 当前表面积
额外体积 = 入流增量 × 扰动持续时间
当前表面积 = 基于库容曲线的分段线性插值结果
```

### 库容曲线表面积计算
```
各段平均表面积 = (V₂ - V₁) ÷ (H₂ - H₁)
其中：V₁,V₂为相邻控制点体积，H₁,H₂为相邻控制点水位
```

### 效果评级计算
```
效果等级 = f(理论水位变化)
显著效果：Δh ≥ 10.0 mm
明显效果：1.0 mm ≤ Δh < 10.0 mm  
轻微效果：0.1 mm ≤ Δh < 1.0 mm
微弱效果：Δh < 0.1 mm
```

## 📋 关键指标说明

### 水库参数指标
- **初始水位**：当前水库运行水位，影响表面积选择
- **初始体积**：当前水库储水量，验证库容曲线一致性
- **库容曲线**：描述水库几何特性的基础数据
- **表面积**：水位变化计算的关键参数，随水位而变

### 计算结果指标  
- **额外体积**：扰动期间净增加的水量
- **当前表面积**：目标水位段的平均表面积
- **理论水位变化**：基于物理原理计算的预期变化
- **效果等级**：基于工程实践的效果分级评估

### 优化建议指标
- **参数合理性**：当前参数设置的合理程度
- **可观测性**：效果是否足以在仿真中观察
- **优化方向**：参数调整的推荐方向和幅度
- **预期改善**：参数优化后的效果改善预期

## ⚠️ 使用注意事项

### 数据质量要求
- **库容曲线完整性**：确保库容曲线包含当前运行水位段
- **参数一致性**：验证初始体积与库容曲线的一致性  
- **精度要求**：库容曲线精度直接影响计算准确性
- **边界条件**：注意计算水位是否在库容曲线范围内

### 计算假设和限制
- **线性插值假设**：库容曲线段内采用线性插值近似
- **稳态假设**：不考虑动态水流效应对表面积的影响
- **几何简化**：忽略水库复杂几何形状的细节影响
- **时间尺度**：适用于中短期扰动效果计算

### 结果解读要点
- **理论vs实际**：理论计算为理想情况，实际可能存在偏差
- **精度期望**：毫米级变化已属于高精度，需要高质量观测
- **参数敏感性**：表面积的微小变化可能显著影响结果
- **适用范围**：计算结果适用于所设定的水位范围内

### 故障排除指南
- 如果无法加载参数，检查core_lib环境配置
- 如果库容曲线为空，确认YAML配置文件正确性  
- 如果计算结果异常，检查输入参数的合理性
- 如果建议不合理，可能需要手动调整阈值设置
