# 执行器故障扰动仿真演示

基于 `1.test_actuator_failure_disturbance.py` 的Streamlit可视化应用，提供零代码的执行器故障仿真界面。

## 功能特性

- **三种故障类型**：延迟故障、部分故障、完全故障
- **实时仿真**：可视化仿真进度和结果
- **多维度图表**：水位、流量、扰动活跃度的时间序列分析
- **交互式配置**：通过UI界面配置扰动参数

## 运行方式

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
streamlit run app.py
```

## 使用步骤

1. **配置环境**：在侧边栏设置项目根路径，确保能导入core_lib
2. **加载仿真**：设置场景目录并加载仿真环境
3. **添加扰动**：在"扰动配置"标签页中添加三种故障类型
4. **运行仿真**：在"运行与结果"标签页中执行仿真并查看结果

## 故障类型说明

- **延迟故障**：控制信号延迟生效，模拟执行器响应延迟
- **部分故障**：执行器效率下降，模拟性能退化
- **完全故障**：执行器无响应，模拟完全失效
