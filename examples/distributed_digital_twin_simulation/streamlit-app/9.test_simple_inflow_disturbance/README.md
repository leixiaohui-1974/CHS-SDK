# 简单入流扰动测试系统 - Streamlit应用

这个Streamlit应用为 `9.test_simple_inflow_disturbance.py` 脚本提供了一个直观易用的图形界面，让非技术人员也能轻松进行入流扰动测试和验证。

## 🎯 业务功能

### 核心业务逻辑
- **直接入流扰动**：通过直接修改水库入流参数来验证扰动效果，绕过复杂的扰动框架
- **理论计算验证**：基于物理原理（体积变化/表面积）预测水位变化，并与实际结果对比
- **实时状态监控**：记录仿真过程中的水位、入流、体积等关键状态变化
- **物理核心验证**：验证入流扰动是否能够影响底层物理计算核心
- **精度分析评估**：量化分析理论预期与实际结果的准确度

### 模块依赖
- **core_lib.io.yaml_loader** (SimulationBuilder)：负责加载仿真环境和水库组件
- **使用core_lib**：直接调用核心库进行仿真计算，验证扰动对物理核心的影响

### 数据源
- **仿真环境状态数据**：实时水库状态、组件参数
- **水库组件参数**：初始入流、水位、表面积、体积等物理参数
- **理论计算结果**：基于物理公式的预期水位变化量
- **扰动监控数据**：扰动期间的状态变化记录

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行应用
```bash
streamlit run streamlit_app.py
```

### 3. 访问界面
应用启动后会自动打开浏览器，或手动访问 `http://localhost:8501`

## 📋 功能特性

### 参数配置界面
- **基本参数设置**：初始入流量(50-200 m³/s)、水库表面积(1e5-5e6 m²)、初始水位(10-25m)
- **扰动时间配置**：扰动开始/结束时间、总仿真时间可调
- **扰动强度设置**：扰动入流量可调节，实时显示入流增量
- **理论计算展示**：自动计算预期的水位变化和额外体积

### 实时计算功能
- **理论预测**：基于 `水位变化 = (入流增量 × 持续时间) ÷ 表面积` 计算
- **参数联动**：各参数实时联动更新，立即显示计算结果
- **单位换算**：水位变化同时显示毫米和米单位
- **配置验证**：实时验证参数合理性

### 仿真运行监控
- **双模式支持**：真实仿真（使用core_lib）和模拟仿真（数学模型）
- **状态记录**：每个仿真步骤记录时间、水位、入流、体积、扰动状态
- **实时反馈**：显示仿真进度和状态变化
- **错误处理**：完善的错误处理和用户提示

### 结果分析可视化
- **关键指标KPI**：初始/最终水位、理论变化、准确度四大指标
- **双层时序图**：水位变化曲线 + 入流变化曲线，清晰展示扰动过程
- **理论对比线**：图表中标注初始水位和理论最终水位基准线
- **扰动区间标识**：红色半透明区域标识扰动作用时间段

## 📝 关键计算公式

### 理论水位变化
```
额外体积 (m³) = 入流增量 (m³/s) × 扰动持续时间 (s)
水位变化 (m) = 额外体积 (m³) ÷ 水库表面积 (m²)
```

### 准确度评估
```
绝对误差 (m) = |实际水位变化 - 理论水位变化|
相对误差 (%) = (绝对误差 / |理论水位变化|) × 100%
准确度 (%) = 100% - 相对误差 (%)
```

### 体积-水位关系
```
简化模型：体积 (m³) = 水位 (m) × 表面积 (m²)
实际情况：体积关系可能是非线性的，取决于水库形状
```

## ⚠️ 使用注意事项

### 参数设置建议
- **表面积**：应设置为合理的水库规模，过小会导致水位变化过大
- **扰动强度**：入流增量不宜过大，建议为初始入流的10-50%
- **扰动时间**：建议设置较短的扰动时间以观察明显效果
- **总时间**：应足够长以观察扰动后的系统稳定

### 结果解读要点
- **理论准确度**：90%以上表示仿真计算较为准确
- **水位变化**：毫米级变化在大型水库中是正常的
- **仿真步数**：步数过少可能影响结果精度
- **误差来源**：可能包括数值精度、模型简化、时间离散化等

### 故障排除
- 如果水位无明显变化，尝试增加入流增量或表面积减小
- 如果准确度很低，检查参数设置是否合理
- 如果仿真报错，确认core_lib环境是否正确配置
- 模拟模式下结果仅供参考，实际效果以真实仿真为准
