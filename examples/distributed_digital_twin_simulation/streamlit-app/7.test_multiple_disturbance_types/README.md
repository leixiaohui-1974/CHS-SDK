# 分布式数字孪生仿真：多种扰动类型测试 - Streamlit应用

这个Streamlit应用为 `7.test_multiple_disturbance_types.py` 脚本提供了一个直观易用的图形界面，让非技术人员也能轻松进行扰动仿真测试。

## 🎯 业务功能

### 核心业务逻辑
- **入流扰动**：模拟水库入流量变化对系统的影响
- **传感器噪声扰动**：模拟传感器测量误差对监控系统的影响  
- **多扰动交互**：观察多个扰动同时作用时的系统响应
- **实时监控**：记录水位、流量、容积等关键指标变化
- **结果分析**：量化扰动效果，提供数据统计和可视化

### 模块依赖
- **core_lib.io.yaml_loader** (SimulationBuilder)：负责加载仿真环境配置
- **core_lib.disturbances.disturbance_framework**：提供扰动类型定义和管理
- **使用核心库**：完全集成CHS-SDK核心库进行仿真计算

### 数据源
- **YAML配置文件**：仿真环境和组件配置
- **仿真状态数据**：实时水库状态数据
- **扰动历史记录**：扰动应用历史和效果记录

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行应用
```bash
streamlit run streamlit_app.py
```

### 3. 访问界面
应用启动后会自动打开浏览器，或手动访问 `http://localhost:8501`

## 📋 功能特性

### 仿真配置
- **时间设置**：可调节仿真总时长（10-100秒）
- **扰动类型选择**：支持入流扰动和传感器噪声两种类型
- **参数调整**：直观的滑块和输入框配置扰动参数

### 实时可视化
- **多指标监控**：同时显示水位、入流量、容积、活跃扰动数量
- **扰动区间标识**：图表中清晰标识不同扰动的作用时间
- **交互式图表**：支持放大、缩小、数据点查看等交互操作

### 数据分析
- **统计指标**：提供平均值、标准差、极值等统计数据
- **扰动效果分析**：量化每个扰动对系统的具体影响
- **对比分析**：扰动前中后的系统状态对比

## 🎨 界面设计

### 核心组件
- **SimulationManager类**：封装仿真逻辑和状态管理
- **自适应模式**：支持真实仿真和模拟数据两种模式
- **数据处理**：高效的数据结构和处理算法

### 兼容性设计
- **优雅降级**：核心库不可用时自动切换到模拟模式

- **状态管理**：基于Streamlit会话状态的数据持久化

## 📊 使用场景

### 水利工程
- **调度策略验证**：验证不同调度策略的效果
- **风险评估**：评估异常情况对系统的影响
- **应急演练**：模拟突发事件的应对效果

### 系统测试
- **鲁棒性测试**：测试系统在扰动下的稳定性
- **传感器故障分析**：分析传感器故障对监控的影响
- **多重故障场景**：测试多个问题同时发生时的系统表现

### 培训演示
- **原理演示**：直观展示扰动对系统的影响
- **参数敏感性分析**：展示不同参数设置的效果差异
- **决策支持**：为管理决策提供数据支持

## 🛠️ 扩展开发

### 添加新扰动类型
1. 在 `SimulationManager` 中添加对应的扰动创建逻辑
2. 在界面中添加新的配置选项卡
3. 更新结果分析部分以支持新扰动类型

### 自定义可视化
1. 修改 `make_subplots` 配置添加新的子图
2. 在数据分析部分添加新的统计指标
3. 扩展导出功能支持更多格式

## 📝 注意事项

- 确保CHS-SDK环境正确配置
- 仿真时间设置要合理，过长可能影响性能
- 扰动参数设置要符合实际物理约束
- 建议在测试环境中先验证配置的正确性
