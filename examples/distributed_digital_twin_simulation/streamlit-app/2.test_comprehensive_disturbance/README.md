# 综合扰动仿真演示应用

基于 `2.test_comprehensive_disturbance.py` 的Streamlit可视化应用，提供综合扰动测试的交互式界面和结果分析。

## 功能特性

- **两种测试模式**：综合扰动测试和扰动相互作用测试
- **实时可视化**：多维度图表展示仿真结果
- **智能分析**：扰动效果分析、相互作用分析、系统韧性评估
- **业务流程图**：可视化展示物理系统、智能体和扰动的关系
- **日志捕获**：自动记录运行日志并支持下载

## 运行方式

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
streamlit run app.py
```

## 使用步骤

1. **配置脚本路径**：确认脚本路径指向正确的 `2.test_comprehensive_disturbance.py`
2. **选择测试**：点击相应按钮运行综合扰动测试或扰动相互作用测试
3. **查看结果**：运行完成后立即显示可视化结果和分析
4. **下载数据**：在"结果与下载"标签页下载JSON结果和日志文件

## 可视化功能

### 综合扰动测试
- **系统响应分析**：水位变化、流量变化、消息延迟、扰动活跃度
- **扰动效果分析**：扰动类型分布饼图、系统响应指标
- **性能指标**：仿真步数、消息成功率、执行时间

### 扰动相互作用测试
- **相互作用可视化**：系统状态叠加效应、扰动强度时序、通信质量变化
- **相互作用分析**：扰动相互作用强度热力图
- **系统韧性评估**：适应能力、恢复能力、鲁棒性、冗余度雷达图

## 技术特点

- **动态模块加载**：无需修改原脚本，动态导入执行
- **日志捕获**：自动捕获Python logging输出
- **交互式图表**：使用Plotly提供丰富的交互式可视化
- **结果持久化**：运行结果保存在session_state中

## 系统架构

应用展示了以下组件间的关系：
- **物理组件**：上游水库、控制闸门、下游水库
- **智能体**：ReservoirAgent、GateAgent、CoordinationAgent
- **扰动类型**：物理扰动、网络扰动、动态扰动

## 注意事项

- 确保 `2.test_comprehensive_disturbance.py` 脚本存在且可执行
- 图表显示依赖于脚本返回的历史数据结构
- 可选安装 graphviz 以显示业务流程图
