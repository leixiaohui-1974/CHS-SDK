# 渠道系统 PID 控制策略对比

本示例展示了一个简化的两级灌溉渠道系统，并比较 **本地上游水位控制** 与 **远程下游水位控制** 两种 PID 策略在相同运行条件下的表现。脚本通过解析方式建立质量守恒方程和线性化闸门能力模型，可在秒级完成两种工况的仿真和性能评价。

## 物理组件与拓扑结构

系统包含以下核心单元（括号内为关键参数）：

- **上游水库**（常年来水 18 m³/s，等效水面 10 000 m²）。水位变化由净入流积分得到，用于提供控制策略的边界条件。
- **闸门 1**（线性化最大过水能力 36 m³/s）。位于水库与渠道 1 之间，用于调节进入干渠的流量。
- **渠道 1**（等效蓄水面积 5 500 m²，目标水位 5.0 m）。代表闸间主干渠，水位通过闸门 1 与闸门 2 的流量差更新。
- **闸门 2**（线性化最大过水能力 36 m³/s）。位于渠道 1 与渠道 2 之间，是下游用户的直接供水调节设备。
- **渠道 2**（等效蓄水面积 4 800 m²，目标水位 4.5 m）。代表尾水池，下游恒定需求为 18 m³/s。

拓扑结构遵循“水库 → 闸门 1 → 渠道 1 → 闸门 2 → 渠道 2 → 下游需求”的单向串联系统，保证质量守恒并便于跟踪每个节点的水量。

## 控制策略与仿真设定

| 策略 | 闸门 1 控制逻辑 | 闸门 2 控制逻辑 | 主要反馈信号 |
| ---- | ---------------- | ---------------- | ------------ |
| 本地上游控制 | 固定开度 0.50，用于模拟稳定供水边界 | PID（Kp=-0.9, Ki=-0.012, Kd=-0.08，偏置 0.50） | 渠道 1 水位（目标 5.0 m） |
| 远程下游控制 | PID（Kp=-0.7, Ki=-0.007, Kd=-0.06，偏置 0.50） | PID（Kp=-0.9, Ki=-0.012, Kd=-0.08，偏置 0.50） | 渠道 1 / 渠道 2 水位（目标分别为 5.0 m / 4.5 m） |

仿真时长为 7 200 s，时间步长 10 s。脚本 `run_pid_comparison.py` 会顺序运行两个策略，生成 `results_local_upstream.csv` 与 `results_distant_downstream.csv`，并输出控制性能汇总表。

运行命令：

```bash
python examples/canal_model/canal_pid_control/run_pid_comparison.py
```

## 结果分析

脚本会自动计算以下指标并给出 0–100 的得分：

- **稳态偏差**与**积分绝对误差**衡量设定值跟踪能力；
- **最大超调 / 欠调**反映响应平稳性；
- **稳定时间**为信号进入 ±1% 容差带后的第一个时刻。

在当前配置下，两种策略均可保持渠道水位与设定值严格一致（偏差与超调为 0），因此两个场景的评分均为满分 100。结果也印证了线性能力模型在负荷均衡工况下的可控性：

- 本地控制通过闸门 2 快速吸收微小扰动；
- 远程控制在闸门 1/2 双闭环配合下，同步守住中游与尾水池水位目标。

## 讨论与建议

1. **扰动验证**：若要评估扰动鲁棒性，可在脚本中加入来水或需求的阶跃变化，观察 PID 积分项是否仍能消除稳态误差。
2. **参数整定**：当前增益适用于线性化模型。若在真实系统中存在非线性，可结合阶跃试验或使用 Ziegler–Nichols 等方法重新整定。
3. **硬件约束**：线性能力模型默认闸门全开时可提供 36 m³/s。若实际能力不足，应相应调整 `gate1_capacity` / `gate2_capacity` 并重新评估控制余量。
4. **拓展方向**：可以将脚本输出接入更高层的调度优化或可视化模块，形成渠道群联合运行的基准案例。

通过该示例，读者可以快速搭建、运行并量化两种典型 PID 策略，为后续引入更复杂的 MPC 或协同控制算法打下基础。
