# CHS-SDK 魔数重构总结

## 概述

本次重构解决了 core_lib 模块中大量硬编码魔数的问题，通过创建统一的配置系统来提高代码的可维护性、可读性和可配置性。

## 问题分析

### 发现的魔数类型

1. **物理常量** - 如重力加速度 (9.81)、水密度 (1000) 等
2. **数学常量** - 如圆周率 (π)、各种指数等
3. **单位转换常量** - 如功率转换系数 (1000)、百分比转换 (100) 等
4. **默认配置参数** - 如默认直径 (0.5)、默认表面积 (10000) 等
5. **仿真参数** - 如默认时间步长 (1.0)、打印间隔 (10) 等
6. **硬编码的业务参数** - 如水位 (25.0, 8.0)、功率 (50.0) 等

### 影响范围

- `core_lib/physical_objects/` - 物理对象模块
- `core_lib/local_agents/` - 本地智能体模块
- `core_lib/central_agents/` - 中央智能体模块
- `core_lib/core_engine/` - 核心引擎模块
- `core_lib/disturbances/` - 扰动模块
- `core_lib/hydro_nodes/` - 水力节点模块

## 解决方案

### 1. 创建常量定义系统

**文件**: `core_lib/config/constants.py`

定义了以下常量类：
- `PhysicalConstants` - 物理常量
- `MathematicalConstants` - 数学常量
- `UnitConversionConstants` - 单位转换常量
- `HydraulicConstants` - 水力工程常量
- `DefaultConfigParameters` - 默认配置参数
- `SystemLimits` - 系统限制常量
- `StatusConstants` - 状态枚举常量
- `ValidationConstants` - 配置验证常量

### 2. 创建参数管理系统

**文件**: `core_lib/config/parameter_manager.py`

提供以下功能：
- 统一的参数管理接口
- 从配置文件加载参数
- 参数验证和默认值管理
- 支持参数热更新
- 分类管理不同类型的参数

### 3. 创建配置示例

**文件**: `core_lib/examples/parameter_config_example.yml`

展示了如何正确配置各种参数，避免硬编码。

## 重构内容

   - 从参数管理器获取默认参数

3. **`core_lib/physical_objects/unified_canal.py`**
   - 替换硬编码的默认参数
   - 使用参数管理器获取渠道相关参数
   - 保持物理常量的正确引用

4. **`core_lib/local_agents/ontology_simulation_agent.py`**
   - 替换硬编码的仿真参数
   - 使用参数管理器获取传感器参数

### 重构前后对比

#### 重构前
```python
# 硬编码魔数
self.GRAVITY_ACCELERATION = 9.81
self.DEFAULT_DIAMETER = 0.5
self.DEFAULT_EFFICIENCY = 0.8
upstream_level = action.get('upstream_level', 25.0)
```

#### 重构后
```python
# 使用配置系统
self.GRAVITY_ACCELERATION = PhysicalConstants.GRAVITY_ACCELERATION
self.DEFAULT_DIAMETER = self.param_manager.get_parameter('physical_objects', 'default_diameter', 0.5)
self.DEFAULT_EFFICIENCY = self.param_manager.get_parameter('pump_parameters', 'default_efficiency', 0.8)
default_upstream_level = self.param_manager.get_parameter('business_scenarios', 'pump_station.upstream_level', 25.0)
upstream_level = action.get('upstream_level', default_upstream_level)
```

## 使用方式

### 1. 基本使用

```python
from core_lib.config.parameter_manager import get_parameter_manager
from core_lib.config.constants import PhysicalConstants

# 获取参数管理器
param_manager = get_parameter_manager()

# 获取物理常量
gravity = PhysicalConstants.GRAVITY_ACCELERATION

# 获取配置参数
diameter = param_manager.get_parameter('physical_objects', 'default_diameter')
```

### 2. 自定义配置

```python
# 设置自定义参数
param_manager.set_parameter('business_scenarios', 'pump_station.upstream_level', 30.0)

# 从配置文件加载
param_manager.load_config('custom_config.yml')
```

### 3. 参数验证

```python
# 验证配置完整性
is_valid = param_manager.validate_configuration()

# 验证特定参数范围
from core_lib.config.constants import validate_parameter_range
validate_parameter_range(value, 'diameter', 0.001, 100.0)
```
